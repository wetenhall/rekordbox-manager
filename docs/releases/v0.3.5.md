First public preview of Rekordbox Manager: a local desktop app for reviewing
Rekordbox playlist beat grids, adjusting drop markers and preparing 16-bar memory
cue countdowns, with backed-up import on a verified Mac installation.

## Download the app

- **Windows 10/11 x64:** `Rekordbox-Manager-0.3.5-Windows-x64.zip`
- **Mac with an M-series chip:** `Rekordbox-Manager-0.3.5-macOS-Apple-Silicon.zip`
- **Mac with an Intel processor:** `Rekordbox-Manager-0.3.5-macOS-Intel.zip`

Mac packages target macOS 12 or later. No Python installation is needed.
Extract the entire ZIP. On Windows, open `Rekordbox Manager.exe` and keep the
`_internal` folder beside it. On Mac, move `Rekordbox Manager.app` to Applications.
Use the app ZIPs below; GitHub's “Source code” archives are for developers.

## Included

- Regular playlist browsing from the local encrypted Rekordbox library.
- Audio playback, waveform seeking, zoom/pan and metronome preview.
- Small beat-grid timing/drift suggestions and manual first-drop/bar-one alignment.
- First/second drop suggestions, draggable markers and beat/bar/off snapping.
- 16-bar countdown memory cues with slot budgeting and existing cue/loop preservation.
- Independent grid/cue options, cue rebuilds and one batch import confirmation.
- Checksummed backups, guarded restore and local diagnostics.
- Space to play/pause and Up/Down to switch tracks.

See the [README](https://github.com/wetenhall/rekordbox-manager#built-in-functions)
for the full feature list and usage guide.

## Compatibility and known limits

**Windows is analysis/preview only.** Saving is enabled only with **Rekordbox
7.2.19.0342 on macOS** and supported local constant-tempo 4/4 MP3/WAV files at
44.1 or 48 kHz. Other installations remain read-only. Smart playlists, cloud/synced
records and variable-tempo grid writes are not supported. Hardware/USB export has
not been validated.

Automatic detection can choose the wrong drop or bar start. Audition and correct
the suggestions before import. Close Rekordbox and make a library backup first.
Backups cover the database and changed analysis files, not your audio collection.

The app is unsigned on Windows and ad-hoc signed, not notarized, on Mac. OS security
prompts may appear. Do not disable system protection globally.

All three packages pass their OS-specific automated suite and a frozen-app smoke
test using generated audio and a disposable library before publication. This does
not establish real-library compatibility on Windows or every macOS version.
`SHA256SUMS.txt` contains the checksums for the downloadable packages.
