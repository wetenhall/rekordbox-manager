Rekordbox Manager 0.3.73 brings the current playlist, cue-review and Organiser workflows to downloadable Mac and Windows packages.

## Download

- **Mac with an M-series chip:** `Rekordbox-Manager-0.3.73-macOS-Apple-Silicon.zip` — macOS 12.3 or later.
- **Mac with an Intel processor:** `Rekordbox-Manager-0.3.73-macOS-Intel.zip` — macOS 12 or later.
- **Windows 10/11 x64:** `Rekordbox-Manager-0.3.73-Windows-x64.zip` — analysis and preview only.

No Python installation is required. Extract the complete ZIP. On Mac, move `Rekordbox Manager.app` to Applications. On Windows, keep the `_internal` folder beside the executable. Use these app ZIPs, rather than GitHub's source-code archives.

## Changes since the previous downloadable preview

- Cleaner, consistent Manager, Imports and Organiser layouts with a folder/playlist browser and compact track rows.
- Bass-focused waveform previews with red memory-cue markers in the playlist table.
- Check saved memory cues against the app's pattern, compare original and proposed waveforms, adjust both drops, rebuild cues and choose whether to keep or replace the originals.
- Manual beat-grid shifts and drop alignment, hold-to-preview Cue playback, keyboard transport, and automatic navigation to the next track requiring review.
- One Imports queue collects prepared cue/grid edits from multiple playlists, deduplicating shared tracks.
- Organiser scans library usage and finds tracks outside regular playlists. Create draft folders and playlists; drag folders/playlists to nest or reorder them.
- Select one or multiple scanned tracks using clicks, Cmd/Ctrl-click, Shift-click or checkboxes, then drag them onto existing or draft playlists.
- Queued playlist assignments immediately leave the unassigned filters and update the count. Discarding the assignments restores those tracks. Existing memberships and audio files are preserved.
- Review folder, playlist and track-assignment drafts in **Imports → Playlist changes**, then choose **Import playlist changes** to apply them with a backup.

## Applying Organiser changes

Dragging tracks queues changes; it does not immediately write to Rekordbox. Keep Manager open, close Rekordbox, open **Imports**, select **Playlist changes**, review the changes and click **Import playlist changes**. Reopen Rekordbox after a successful import.

Pending cue/grid edits and Organiser drafts are stored only for the current app session. Import or discard them before closing Manager or reconnecting the library.

## Compatibility and known limits

Saving is gated to **Rekordbox 7.2.19.0342 on macOS** with the supported database schema. Grid/cue writes support local constant-tempo 4/4 MP3/WAV tracks; Windows and unsupported installations remain read-only. Smart playlists, cloud/synced records and variable-tempo grid writes are not supported.

Organiser membership and hierarchy writes are experimental. Disposable plain/encrypted database tests cover preservation, stale inputs, rollback and restoration; native Rekordbox reopen and hardware/USB export behaviour for these new writes has not been verified. Automatic cue/drop suggestions still need listening and review.

Packages are unsigned on Windows and ad-hoc signed, not Developer ID signed or notarized, on Mac. macOS may require approval under **System Settings → Privacy & Security**. Do not disable system protection globally.

Each package passes its platform's tests and a packaged-app smoke test using generated audio and a disposable library. Mac packages also pass the embedded-binary compatibility audit. These checks do not establish compatibility with every real library. `SHA256SUMS.txt` contains the download checksums.
